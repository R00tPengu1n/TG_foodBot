# FoodBot — Telegram-бот с рецептами

[English](README.md) | **Русский**

Асинхронный Telegram-бот, который подбирает случайные рецепты из выбранной категории блюд, переводит их на русский язык и присылает вместе со списком ингредиентов.

Данные берутся из открытого API [TheMealDB](https://www.themealdb.com/api.php).

## Возможности

- Поиск случайных рецептов по категории: `/category_search_random <количество>`
- Категории загружаются из API и выводятся кнопками
- Выбор рецептов без повторов
- Параллельная загрузка рецептов через `asyncio.gather`
- Перевод названий, инструкций и ингредиентов на русский язык
- Разбивка длинных рецептов на несколько сообщений с учётом лимита Telegram
- Отмена поиска на любом шаге: `/cancel`
- Меню команд и описание бота в профиле Telegram

## Стек

- Python 3.12+
- [aiogram 3](https://docs.aiogram.dev/) — фреймворк для Telegram-ботов
- [aiohttp](https://docs.aiohttp.org/) — асинхронные HTTP-запросы
- [googletrans](https://pypi.org/project/googletrans/) — перевод текста
- [python-dotenv](https://pypi.org/project/python-dotenv/) — загрузка настроек из `.env`

## Установка и запуск

1. Клонируйте репозиторий:

```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
   cd YOUR_REPO
```

2. Создайте и активируйте виртуальное окружение:

```bash
   python -m venv .venv
```

   Windows:

```bash
   .venv\Scripts\activate
```

   Linux / macOS:

```bash
   source .venv/bin/activate
```

3. Установите зависимости:

```bash
   pip install -r requirements.txt
```

4. Создайте файл `.env` по образцу `.env.example` и укажите токен бота, полученный у [@BotFather](https://t.me/BotFather):

```
   BOT_TOKEN=your_telegram_bot_token
```

5. Запустите бота:

```bash
   python bot_main.py
```

## Как пользоваться

1. Отправьте боту `/category_search_random 3`, где `3` — количество рецептов (от 1 до 10).
2. Выберите категорию кнопкой.
3. Бот предложит варианты блюд — нажмите «Покажи рецепты».
4. Каждый рецепт придёт отдельным сообщением: название, инструкция и ингредиенты.

## Технические решения

- **Конечный автомат (FSM).** Диалог поиска построен на `FSMContext` из aiogram: каждый шаг — отдельное состояние, данные между шагами хранятся в хранилище FSM.
- **Отдельный клиент API.** Вся работа с TheMealDB вынесена в класс `MealDBClient` — асинхронный контекстный менеджер, который управляет HTTP-сессией. Сетевые ошибки, таймауты и ошибочные HTTP-статусы преобразуются в собственное исключение `MealDBError`, поэтому обработчики не зависят от деталей `aiohttp`.
- **Параллельные запросы.** Рецепты и переводы загружаются одновременно через `asyncio.gather`. Количество одновременных запросов к сервису перевода ограничено `asyncio.Semaphore`.
- **Устойчивость к сбоям.** Если сервис перевода недоступен, бот показывает текст на английском и пишет предупреждение в лог, а не падает.
- **Конфигурация через окружение.** Токен не хранится в коде и читается из `.env`.

## Ограничения

- Перевод работает через неофициальный API Google Translate (`googletrans`). Google может временно ограничивать количество запросов (HTTP 429) — в этом случае рецепты выводятся на английском.
- Состояние диалога хранится в памяти (`MemoryStorage`) и сбрасывается при перезапуске бота.
